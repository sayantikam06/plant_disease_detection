# AI Plant Disease Detection

An AI-powered web application that detects plant leaf diseases from uploaded images using a MobileNetV2 deep learning model.

## Features
- Upload a plant leaf image
- Predict plant disease using AI
- Confidence score for predictions
- Responsive web interface
- Flask backend
- MobileNetV2 model

## Tech Stack
- Python
- Flask
- TensorFlow / Keras
- MobileNetV2
- HTML
- CSS
- JavaScript

## Project Structure
- app.py
- predict.py
- train_model.py
- prepare_data.py
- dashboard.html
- dashboard.js
- login.html
- login.js
- style.css
- requirements.txt

## Installation

```bash
git clone https://github.com/sayantikam06/plant_disease_detection.git
cd plant_disease_detection
pip install -r requirements.txt
python app.py
```
